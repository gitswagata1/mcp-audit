# Roadmap

## Vision

The `npm audit` of the MCP ecosystem: know what your AI tools can access in seconds.

## Milestones

### Now

- [ ] SARIF output for GitHub code scanning
- [ ] A GitHub Action wrapper
- [ ] Rule documentation with remediation for each finding

### Next

- [ ] Known-vulnerable and typosquatted package database
- [ ] Policy files (allow-lists per team)
- [ ] Auto-fix suggestions for unpinned packages

### Later

- [ ] Runtime monitoring of tool calls
- [ ] Registry reputation scores
- [ ] IDE extension

## Where this can go

| Direction | Idea |
| --------- | ---- |
| **Startup** | AI-agent security posture management for engineering teams. |
| **Publication** | A measurement study of permissions and secrets in public MCP server configurations. |
